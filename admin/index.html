翻译与发布

中文是原稿

离开文字输入框后开始同步，只处理有修改的内容。译文可以手动润色；下次修改同一段中文时会重新生成。

自动翻译会将待翻译文字发送给 MyMemory，不会发送照片或 GitHub 令牌。免费服务有额度限制，文学表达请校对。服务与额度说明 ↗

连接网站

GitHub 保存你的照片和内容清单。连接后才能发布；保存本地草稿不需要连接。

令牌是什么？如何设置？

令牌相当于只交给后台使用的仓库钥匙。创建 Fine-grained personal access token，选择 Charles-Vibe 仓库，将 Contents 设为 Read and write。不要把令牌填进网站文字或发送给访客。

发布前检查

本地草稿只保存在当前浏览器；发布会把内容提交到 GitHub，随后自动更新网站。若他人已修改线上版本，后台会拦截覆盖并保留你的草稿。
