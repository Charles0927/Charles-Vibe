# Portfolio typefaces

Self-hosted WOFF2 subsets generated by the Google Fonts CSS API for the current portfolio text. New characters fall back to the corresponding system serif font.

- EB Garamond: Latin editorial text.
- Cormorant Garamond, italic 500: Charles’Vibe signature.
- Noto Serif SC / JP / KR: Chinese, Japanese and Korean headings and captions.

Source: https://fonts.google.com/
License originals: https://github.com/google/fonts/tree/main/ofl
The applicable SIL Open Font License files are included in `licenses/`. No proprietary fonts from the reference photographers' websites are redistributed.
